# Finance AccountSelect 级联菜单

- Status: Accepted
- Date: 2026-08-24

## Context

Orbita Finance 的账户单选发生在校验、明细行内编辑和 Composer 等不同范围内。按根数量分别实现控件会使搜索、键盘操作、可选账户规则和无障碍行为漂移；将单选和筛选多选混用又会混淆产品语义。

账本账户以 Beancount 五根组织：Assets、Liabilities、Equity、Income、Expenses。用户希望在宽范围场景中可编辑 Equity posting；校验仍只在 Assets 或 Liabilities 的单根范围内工作。

## Decision

- 单选账户统一使用一个可配置的 `AccountSelect`。调用方以允许的根集合限定范围，而不是为单根、两根或五根另造公开控件。
- `AccountSelect` 使用级联菜单呈现：菜单每一列为当前层级的平铺列表；指向带子项的行时，在右侧贴邻打开下一列。宽范围场景先显示允许的根；单根场景直接显示该根的下一层，不额外显示根选择层。
- 搜索是同一控件的全路径结果模式：搜索框为空时显示级联菜单；输入后隐藏级联列，改为单列、带完整路径的可选叶账户结果；清空搜索即回到级联浏览。搜索不在每一层单独过滤。
- 第一版搜索采用大小写不敏感的全路径包含匹配；不做拼音、错别字或模糊匹配。
- 账户选择器中仅无子项且已 `open` 的账户可选；有子项的路径节点只用于继续展开。该规则只约束新的选择操作，不迁移、不校验或删除历史上已记在父账户的分录。
- 叶 `open` 规则采用 A + C 边界：当前 Finance 编辑只由选择器限制新选择，Finance Commit 不扫描或拒绝历史父账户分录；未来账户创建/管理入口必须阻止新建会成为父节点的 `open` 账户。
- 叶 `open` 规则采用 A + C 边界：当前 Finance 编辑只由选择器限制新选择，Finance Commit 不扫描或拒绝历史父账户分录；未来账户创建/管理入口必须阻止新建会成为父节点的 `open` 账户。
- 若旧分录仍引用后来拥有子项的 `open` 父账户，触发器继续回显该路径；编辑其他字段时保持原值并可保存。该账户不出现在菜单或搜索结果中，用户只有主动重选账户时才必须改选叶账户；不显示警告或阻塞保存。
- 默认显示以账户批注名和友好路径为主，完整 `.bean` 账户名作为灰色次行；搜索同时匹配两者。无批注时使用 `.bean` 名。
- 明细 posting 行内编辑与 Composer 高级的五根管理员模式例外：其**已选值本体框**关闭后只显示完整英文 `.bean` 路径，以与现有条目一致。Posting combobox 打开期间允许框内切为搜索输入（文字可变），但**框高度与外层布局不得改变**；选中或取消后恢复显示 bean 路径。菜单和搜索结果仍可显示批注名主行与 `.bean` 次行。
- 宽范围单选器允许五根，并允许将 Equity 作为 posting。校验场景继续限定为单一 Assets 或 Liabilities 根。筛选多选器 `AccountTreeMultiPicker` 完全不属于本次实施范围：不改组件、数据范围、交互或测试。
- Equity 仅在明细 posting 行内编辑和 Composer 高级中可选。简易 Composer 保持日常语义：支出为 Expenses + Assets/Liabilities，收入为 Income + Assets，转账两端均为 Assets/Liabilities。
- Equity 仅在明细 posting 行内编辑和 Composer 高级中可选。简易 Composer 保持日常语义：支出为 Expenses + Assets/Liabilities，收入为 Income + Assets，转账两端均为 Assets/Liabilities。

## Consequences

- 账户目录、前端 `AccountGroup`、账户 forest 和相关校验需支持 `equity`；现有禁止普通交易使用 Equity 的规则需改为与本决策一致。
- 未来账户创建/管理实现必须具备叶 `open` 约束；这不授权对现有账本迁移、清理或全量 Commit 校验。
- 未来账户创建/管理实现必须具备叶 `open` 约束；这不授权对现有账本迁移、清理或全量 Commit 校验。
- 统一单选控件必须支持不同根集合、级联展开、全路径搜索、键盘操作及历史父账户值的兼容回显；这些是后续实施计划的验收项。
- 组件必须明确区分菜单条目/搜索结果的显示格式与已选值本体框的显示格式；五根管理员模式的本体框在整个交互生命周期保持 `.bean` 全路径稳定，禁止选中态或取消选中态造成跳动。
- 单选级联菜单与筛选多选树保持独立，避免将单选提交与多选/半选状态耦合。
- 实施计划和代码审查必须将筛选多选器排除在本 ADR 的改动范围之外。

## Alternatives considered

- 按校验、Composer、明细分别实现账户选择器：拒绝，重复并会导致行为漂移。
- 多根使用根 Tab 或一棵完整缩进树：拒绝，用户明确选择逐级展开的贴邻级联菜单。
- 只展示 Equity 但不可选：拒绝，宽范围编辑需要允许 Equity posting。

## Open questions

- 无；鼠标、键盘与触屏的打开、关闭和焦点使用标准可访问级联菜单行为。
