## 范围与验收

### 1. Orbita Insight 窗口与 chrome

- [x] 同一 Tauri 进程中提供 `admin` Insight 窗口；Panel 有明确入口，Insight 有 Health、Journal、Finance、Work 四个领域区。
- [x] Insight 使用 admin 专属自绘 frame；Panel 不改为该 frame。
- [x] 关闭 Insight 改为 hide，二次打开复用 webview；代码中已实现。
- [ ] 冷启动 Panel 后打开 Insight：窗口应立即出现 loading，不应等待 Finance Service 而卡数秒。
- [ ] 连续多次“打开 → ✕关闭 → 再打开”：内容不白屏/冻结，且 ─□✕ 始终可点击；左侧可拖动窗口，右侧控制区不可被 drag 覆盖。
- [ ] 同开 Panel 与 Insight：任务栏图标一致；只留 Insight 可见时也不回落为白底图标。

### 2. Orbita Finance 与 Finance Service

- [x] Python Finance Service、FastAPI health/API 与 TypeScript Finance 模块均已迁入当前工作树。
- [x] Finance Service 不在 Panel 启动时拉起；Insight 入口异步 ensure，失败有可见错误和重试入口。
- [x] 资产信息架构已改为 Dashboard Hub + 统计/整理/导入钻取；旧六 tab 平铺被替代。
- [x] Finance 统一页面壳（两列布局、明细右栏记一笔、顶栏全局保存与表单直写分工）已落代码；明细交互仍待 §2 手工验收。
- [x] sidecar stale 检测、非孤儿复用、重试重启和账本初始化/覆写确认已落代码。
- [ ] 使用合法 `{dataDir}/bill` 布局打开资产：sidecar 连接正确数据根，Dashboard 可加载，账户不被误判为未就绪。
- [ ] 保留一个历史 sidecar 占用默认端口时点“重试”：应用不认领该进程，而是以正确数据根在可用端口启动并重新连接。
- [ ] 缺失账本骨架时显示“未就绪”；新建后可连接；非空目录显示覆写确认，不应静默覆盖。
- [ ] 验证明细 500+ 条滚动、同日拖拽、inline 编辑和保存状态机；结果未通过则保留为后续计划风险。

- Dashboard 真实指标/最近交易 API、CSV 导入、分类/账户入口、代码层历史名称清理。
