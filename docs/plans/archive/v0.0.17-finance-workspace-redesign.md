## 1. 目标与硬边界

将 Finance 编辑页重构为：共同轻量顶栏、固定 360px 右侧工作台（筛选/添加/校验）和受管理的 Composer 弹窗。目标是减少视觉卡顿，统一输入控件，并保持账本写入安全。

- 不改 CSV、时间排序、`seq`、Parser、Candidate、Commit、metadata、账本渲染或 `.bean` 格式。
- 不改编辑卡片布局；它仍是接近 `.bean` 的原位编辑页。阅览模式另立计划。
- 不改 Composer 字段、默认值、校验、草稿、状态机、Candidate→atomic Commit、绿勾语义或现有提交后流程；只改入口与弹窗 UI。
- 不做金额筛选、泛化 Beancount Query、估值/自动换汇、默认预设自动应用。
- 所有保存反馈继续服从 ADR 0003：绿色勾仅代表原子 Commit 已确认；reload、统计、测量均后台化且受 generation 保护。

1. 顶栏在 `admin-content` 内横跨主列和右栏，sticky；不跨左 Admin 导航，不做独立白色悬浮卡。
2. 左侧保留返回；右侧保留保存、左/右栏开关。导入与筛选移出顶栏。

## 4. 右栏模块（从上到下同时出现）

### 筛选

- 即时生效、无应用按钮；不同组为 AND：日期 AND 类型 AND 账户条件 AND 标签条件。保留滚动位置可行时；校验后台刷新不得阻塞列表。
- 标题右侧仅有条件生效时显示“重置”：恢复全部时间、全部类型、无账户、无标签；若校验跟随筛选日期，重置后回到当前余额、隐藏期间统计，无确认。
- 日期：一个范围触发器；同一日历首击即作为单日生效并保持打开，第二击扩展范围。范围已完成后，任意再点日期都开始一轮新选择：该日立即作为单日/新起点生效，下一击才完成新范围；不在既有范围内猜测用户要改哪一个端点。若正在等待第二击而第二点早于起点，则取消原较晚起点、改以这个较早日期作为新起点，等待下一击完成范围。默认全部时间。快捷范围：今天、近7天、本月、今年、全部时间；快捷范围保存相对语义，手选保存绝对日期。
- 类型：扩展为 8 项多选：支出、代支出、收入、转账、还款、未分类、Pad、Balance；右栏 2×4 复选网格与“全部”重置。Pad 与 Balance 不再是类型筛选之外的例外，只有各自被选中才显示。八项均取消时明确显示真正空结果，不得把视觉“全不选”偷换为“全部类型”；点击“全部”恢复八项。未分类无独立颜色，等同卡片底色/无色条；勾选靠 checkbox 与选中表面表达。
- 账户：使用 `AccountTreeMultiPicker`，可搜索、无限多选、普通级联复选树。父项勾选/取消整棵子树；子项独立勾选；父项全选/半选/未选。不得做自动父子替换、隐式排除或数量上限。账户组默认 OR，可切换 AND。已选少时为可移除 chips，多时前几个+`+N`/“已选 N 个账户”。
- 标签：使用 `TagPicker`，可搜索平铺列表、无限多选，默认 OR、可切换 AND；chips 多时同样摘要。标签列表必须在完整条目索引可用后才声称“全部标签”。
- `SearchableSelectPopover` 仅供平铺选择（TagPicker）：统一搜索框、选项、空态、选中态、最大高度、隐藏滚动条、键盘；不承载树或业务语义。账户树独立实现。

### 添加

- 一行两个视觉同权按钮：`+ 记一笔`、`导入 CSV`；均只启动既有流程，不在右栏嵌表单。
- Composer 置于既有受管理 modal/dialog 根：日期分组 `+` 预填该组日期；右栏按钮预填上海当天，若筛选精确为单日则预填该日；无空日期/fallback。
- 弹窗有取消/保存/保存并继续记一笔。普通保存成功关闭；保存并继续在成功后开下一张，保留日期、时间、类型、账户，清空收款人、备注、标签、金额。
- 未编辑可直接关闭；编辑后所有关闭路径（遮罩、Esc、关闭、取消）均确认继续编辑/放弃。

### 校验

- `AccountSelect` 独立于多选树：精确单选，只选真实存在且当前场景允许的账户；父目录只作导航/分组，不能选为聚合目标。校验限资产、负债/信贷账户。
- 默认“跟随筛选日期”开；关闭后才显示独立日期范围。无日期显示当前余额；有日期显示期初、流入/消费、流出/还款、净变动/欠款变化、期末、笔数，2×3 紧凑展示。
- 多币种不估值：`@@ 700 CNY` 直接使用明确 `700 CNY` 作为期间统计；无 `@@` 显示原币种；不使用 `@` 或历史汇率推算。余额按实际持仓币种。
- 切换账户/日期只局部 LoadingIndicator，旧结果不可伪装为新结果；generation 丢弃过期响应。

## 5. 搜索

- 搜索是当前右栏筛选结果中的“查找”，不改变列表集合、排序、滚动状态或筛选状态。
- 范围：全部（默认）/收款人+摘要/账户/标签/金额。全部仅索引这些业务字段及币种；不搜 Beancount 语法、flag、link、内部 metadata、orbita-id、日期、时间。
- 忽略大小写与空白，连续文本精确匹配；不做拼音、模糊或错别字匹配。交易是结果单位，多字段命中仍只计一笔，卡片内全部命中字段轻量高亮。
- 顶栏显示范围、`当前/总数`、上/下、关闭。Enter 下一个，Shift+Enter 上一个，Esc 关闭（补全开着时先收补全），Ctrl/Cmd+F 聚焦。
- 最多 6 个字段值补全；按当前筛选结果与范围取值。↑↓移动、Tab采用且留焦点、Enter有补全先采用否则跳下一个。采用补全立即刷新计数/高亮但不自动定位。
- 必须预建规范化本地索引；键入仅更新搜索状态、计数和已渲染卡片高亮。不得请求服务端、跑 Parser、排序、filter/reconcile 或测量；IME composition 结束后下一帧合并计算。

## 6. 配置预设与校验

- 保存日期、类型、账户集合+OR/AND、标签集合+OR/AND；不保存全文搜索、校验账户/日期。预设下拉：选即应用、保存当前为…、更新当前、删除。

## 9. 已确认的筛选语义与实现护栏

以下是已定产品语义；实现不得用既有内部状态的便利性改变它们。

1. **反向日期点选（已确认）**：先点较晚日期、再点较早日期时，取消原起点，以新较早日期作为新起点，等待第三次点选；不自动归一为范围。已完成范围后再点任意日期也开始一轮新的两段式选择。
2. **类型全取消（已确认）**：升级为显式 `all | selected Set`，筛选项为六种交易类型加 Pad、Balance 共八项；八项均取消显示真正空结果，“全部”恢复八项。Pad/Balance 不再绕过类型筛选。不得再用空 Set 兼作全部类型。
3. **账户 AND（已确认）**：一笔交易只须有 postings 分别命中每一个已选账户/展开子树即可，是所选账户集合的子集，不要求交易 postings 与所选集合完全相等；OR 则任一命中即可。
4. **非 Transaction 条目（已确认）**：账户筛选时 `Balance`/`Pad` 仅在其目标账户命中时显示；标签筛选时它们没有 tag，故不显示。日期过滤仍一律适用。
5. **金额查找（已确认）**：本轮只有金额/币种文本查找，例如 `-397.24`、`CNY`；不解释成比较、区间、成本金额或汇率查询。

## 11. 后续收束护栏（已确认，未验收）

本节记录阶段 1–6 实施后发现的真实缺口；不得以“测试已绿”或修改文档状态替代修复。

### 11.1 筛选的乐观交互优先于列表派生

- 账户树、标签及类型的点选，控件自身的选中/半选/文案必须在当前事件内完成；不得等待列表过滤、virtual window、卡片 reconcile、统计刷新或网络请求后才显示反馈。
- Store 必须区分轻量的 **filter input state** 与昂贵的 **derived/rendered list**：先同步发布前者给右栏控件，再以 latest-wins、可合并的下一帧/空闲调度计算过滤结果并更新列表。连续点选只能保留最后状态，不得堆积每一次全量派生。
- 不得把 `queueMicrotask()` 当作“让浏览器先绘制”的保证；microtask 仍可能在同一帧 paint 前执行。实现须以真实可观测的首帧反馈为验收标准，并增加长列表下连续勾选的回归/实机验收。
- 这只改变筛选的呈现调度，不改变过滤语义、排序、账本状态或 Candidate/Commit；列表可晚一帧更新，但控件状态不得回跳、滚动位置不得重置。

### 11.2 Settings 预设的耐久与并发

- `filter_presets` 写入须使用已有原子写入机制；普通 `write_text` 不得覆盖配置文件。
- API 返回稳定 revision/ETag，PUT 必须携带 expected revision；不一致返回 409，前端 reload 后让用户重试/重新应用，不得静默后写覆盖先写。
- 配置未知字段、结构损坏和未知 schema version 均保留并给出诊断；未知版本不得按当前 schema 静默读取或覆盖。所有测试只用隔离 data root。

### 11.3 Period stats 的可用失败与真实账本完整性

- configured `write_target` 缺失、不可读、任一 loader error 或受支持 include 缺失时，period stats 必须明确失败并给出可行动诊断；不得返回 `ok: true, currencies: []` 伪装为空余额。
- 输入参数错误保持 400；账本读取/解析/依赖读取失败为 503。真实已提交账本的相对嵌套 `include` 必须可用：以真实数据根只读加载，或受控递归解析并复制 data root 内 include closure，严禁越界读取；不得退回自定义 Parser。
- AccountSelect 只禁止合成、不存在的父目录；若父账户本身在账本中真实声明且可直接记账，应按真实账户规则可选。实现前须用现有账户目录事实验证，不得仅依据“有子账户”拒绝。
