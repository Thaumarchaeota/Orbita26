## 目标

将 Finance 的所有**单选**账户调用统一到可配置 `AccountSelect`：使用贴邻级联菜单与全路径搜索，并按场景限制可见根。账户目录支持 Equity；宽范围管理员编辑可选择 Equity。保持账本写入以 `.bean` 完整账户名为真值。

## 硬边界

- `AccountTreeMultiPicker` 及筛选账户条件完全不在范围内：不得修改其组件、数据范围、交互、样式或测试。
- 不迁移、删除、重写或 Commit 校验历史父账户分录；未来账户创建/管理的叶 `open` 限制仅记录为后续边界。
- Equity 仅在明细 posting 行内编辑和 Composer 高级开放；简易 Composer 的账户范围保持既定日常收支/转账语义。
- 不改 Parser、Candidate、Commit、CSV、账本格式或 dataDir。

## 调用点与模式

| 场景 | groups | 本体框 |
| --- | --- | --- |
| 右栏校验 | 单一 `assets` 或 `liabilities` | 批注/友好路径主行，`.bean` 灰色次行 |
| 明细 posting 行内编辑 | 五根 | 仅完整 `.bean` 路径，稳定不跳动 |
| Composer 高级 posting | 五根 | 仅完整 `.bean` 路径，稳定不跳动 |
| Composer 简易支出分类 / 付款 | `expenses` / `assets + liabilities` | 默认显示 |
| Composer 简易收入分类 / 收款 | `income` / `assets` | 默认显示 |
| Composer 简易转账两端 | `assets + liabilities` | 默认显示 |

默认显示为批注名/友好路径主行与 `.bean` 完整路径灰色次行；无批注时使用 `.bean` 名。菜单空搜索时级联浏览；输入后改为单列全路径叶账户结果。搜索按批注与 `.bean` 路径作大小写不敏感的包含匹配。
