## Insight 实际架构摘要

```text
一个 Tauri 应用
├─ Orbita Panel（main）
└─ Orbita Insight（admin；关闭后 hide/reuse）
   └─ Insight Host：自绘标题栏 / 全局设置 / 核心领域侧栏 / content viewport
      ├─ Health root（placeholder）
      ├─ Journal root（placeholder）
      ├─ Finance root（独立 Ledger destination）
      └─ Work root（placeholder）
```

- Host 缓存领域 root，常规切换只保存恢复状态、deactivate / 隐藏、显示 / activate；`dataDir` 变更才经领域 guard 后 dispose 并重建。
- Host 只拥有导航、root、共享 chrome / modal 与生命周期；领域拥有自身数据、路由、错误和业务 UI。Finance 的 Store、Commit、Service 连接与内部 keep-alive 不迁入 Host。
- Insight 显示不等待 Finance Service；Finance 在自己的 root 内呈现 loading、未就绪和错误。设置入口位于 Host 标题栏，`dataDir` 切换遵循 guard、通知两个窗口与 Finance Service 重启边界。
