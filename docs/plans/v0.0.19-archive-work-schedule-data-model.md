# v0.0.19 Archive / Work / Plan 数据模型设计收束

> **状态**：设计文档阶段；本计划只授权术语、ADR 与架构方向整理，不授权代码、schema、迁移、外部写入或同步服务实现。
> **风险级别**：后续实施为 L3，涉及用户数据、SQLite、同步、外部 TickTick command 与跨端冲突。

## 目标

把已讨论的 Archive Object / Connection、Journal Entry 目标分类、Work、Plan 和 TickTick 适配边界写成可追溯设计，确保未来实施不把领域事实、时间线、连接、外部 command 或同步机制混为一层。

## 本轮交付（文档初稿，仍待维护者确认）

- [-] 将 Domain、Object、ArchiveRef、Connection 与 Member 的 Proposed 术语写入 Glossary；已完成初稿，待维护者确认。
- [-] 新建 ADR 0012：Connection 连接组、引用边界、Journal Entry 目标与兼容诊断；已完成初稿，待维护者确认。
- [-] 新建 ADR 0013：Work/Session/Segment/Plan 目标、local-first 与 TickTick adapter 边界；已完成初稿，待维护者确认。
- [-] 将数据架构愿景从此前候选收束为 Connection 方向；已完成初稿，待维护者确认。

## 后续实施阶段（未授权）

1. **Archive / Journal migration**：先审计当前 `events`、`moods`、`notes` 与目标 Entry 的兼容、旧数据策略、`hasDetail` 与固定 MD 路径、稳定 ID、软删、未知字段保护和回滚；不得直接覆盖现有 SQLite 或 JSON。
2. **Connection foundation**：定义本地 schema、Member 引用校验、嵌套无环、事务 outbox、删除/恢复、反查索引与人工体验；完成 L3 架构/安全、实现、测试、验收四角色证据。
3. **Work / Plan local facts**：独立定义 schema、Project/Node 树约束、Phase 手动完成检查、Session 最终实际起止、Session/Segment/Interval 编辑审计，以及仅由 Segment 明确操作创建/更新 `PlanItem.kind = schedule` 的单向关系；再处理 PlanItem 批量 recurrenceId 修改与 Plan Group 组织元数据。先离线可靠，再接 UI。
4. **Sync Core**：所有可同步 Object 与独立 data-root 复用同一个 Sync Core；Component/严格子 Data 随父 aggregate 原子同步。先完成现有 Sync S0 阻断项（replica、shadow、cursor、ACK、inbox dedupe、canonical snapshot、remote apply、conflict/root 切换），不得直接把 v1 `sync_outbox` 发网络。
5. **TickTick adapter**：服务端成为唯一 Orbita-owned API caller；外部 command 与本地事实同步分离，明确幂等、字段映射、双向冲突、删除/恢复和脱敏运维后再接真实数据。

## 明确不纳入

- 不修改当前 Journal/Health 规格、当前 SQLite 专业事实或已接受 ADR 0009。
- 不迁移当前 Finance `.bean` 真源；Finance v2 仅以 ADR 0014 的 Proposed 方向另立 L3 实施计划。
- 不实现 Travel、Media、Knowledge 的对象模型。
- 不把 Body Measurement、Plan priority、Plan Group 完整树规则、TickTick 映射和 Connection kind/evidence 伪称已决定。
- 不把 Health 事件与测量数据的分类解释为现有 Health schema 已迁移；本轮只固定目标边界。

## 验收门槛（未来实施）

- 每一个新事实可在断网时本地可靠写入，失败不伪造成功。
- Connection 不复制领域 payload、不能成环，删除/恢复与未知字段均有明确行为。
- Journal Document 与 Note 都可带 mood；Health 事件与测量/汇总数据的 Object 边界保持可追溯，Body Measurement 仍由单独设计决定。
- Work 树不跨 Project 成父子、不成环；完成检查、取消软检查、归档门槛符合 ADR 0013。
- Segment 重叠统计按 Interval 并集计算，事后编辑可追溯。
- TickTick 失败不回滚 Orbita 事实；不存在 desktop/server 双写；真实数据上线前通过 L3 证据与用户验收。
