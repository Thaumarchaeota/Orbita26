## 2. 0.0.17 已确认的当前架构与决定

### Orbita Insight

- Orbita 是一个 Tauri 应用、一个可执行文件，包含 Panel（`main`）与 Insight（`admin`）两个 webview；Insight 关闭时隐藏并复用，不是第二个应用。
- Insight Host 只拥有导航、缓存领域 root、共享 chrome/modal 与生命周期；Health、Journal、Finance、Work 是四个 core destination。常规切换只 activate/deactivate 与 hide/show，`dataDir` 切换才经 guard 后 dispose/recreate。
- Finance 是独立 destination：它自己拥有 Store、Commit、Service 连接、错误和内部 keep-alive。Insight 显示不等待 Finance sidecar；Finance 在自身 root 中表示 loading、未就绪与错误。
- Health、Journal、Work 当前是 placeholder；跨领域总览、动态 workspace、统一 Event/Archive 数据模型、`archiveRoot` 与自动迁移均不是 0.0.17 已采用范围。

### Finance

- Finance 数据根是 `{dataDir}/bill`；Parser 只读，Candidate 校验与 Commit 是受控写入边界，sidecar 只由 Insight 异步确保启动。
- 同日排序采用有效 `time` + 确定性比较器；同日拖拽已由 ADR 0002 明确取消。CSV 的 `time` metadata、Candidate/Commit 与重新加载必须保持同一排序语义。
- 保存成功只表示原子 Commit 已确认；reload、统计与余额审计可后台进行且必须受 generation 保护，不能撤销成功反馈。
- 当前 Finance 工作台是共同顶栏、占位式 360px 右栏（筛选/添加/校验）与受管理 Composer modal；筛选、搜索、预设、AccountSelect、period stats 的稳定语义以 Finance spec、`decisions/finance.md`、`decisions/interaction.md`、ADR 0003/0004 与 `UI-PRIMITIVES.md` 为准。
