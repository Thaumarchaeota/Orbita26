# Orbita 交互响应与完成反馈：已定案

## 当前结论

- 绿色勾只表示核心用户意图已经可信确认并可恢复；仅排队或同步中的外部任务必须使用不同状态。
- 派生 reload、统计、缓存和列表测量在核心完成后继续执行，不得阻塞绿色勾。失败保留核心完成事实，并提供非阻塞重试。
- 核心完成后用户可以继续编辑；后台结果必须受 generation/version 守卫，过期结果不得覆盖新编辑。
- 高成本布局变化一次完成逻辑切换，再用 `transform` / FLIP 平滑视觉；不得逐帧重排长列表、滚动区、卡片网格或复杂表单。
- Finance 明细：日期分组由 sticky date pin 承担，交易卡片 identity 行只显示时间；改日期/时间走 portal popover，不在行内展开日期列，避免行宽跳变。
- 侧栏改变外层空间时，具有既定最大宽度的主体只重新居中，不拉满，也不被 drawer 覆盖。

完整背景、边界与替代方案见 [ADR 0003](../adr/0003-perceived-responsiveness-and-durable-completion.md)。
